## FurnitureStore - API
Jag har skapat ett API för att hantera blogginlägg. API:et är skapat i syfte att kunna använda Create, Read, Update, Delete genom GET, POST, PUT, PATCH och DELETE.

### Anslutning till API
API:et är publicerat på Render och har URL:en: https://blogposts-frontendm3.onrender.com. API:et är kopplat till en Postgres-databas.  

### Tabeller i databasen

#### Tabell för Post
| Tabellnamn  | id | title | content | excerpt | image | createdAt | 
| ------------- | ------------- | ------------- | ------------- | ------------- | ------------- | ------------- |
| Post  | SERIAL PRIMARY KEY  | STRING NOT NULL  | STRING NOT NULL  |  STRING NOT NULL | URL | DateTime Autogenerated |


### Hur man använder API:et 
Det finns olika sätt att använda API:et för att nå det, nedan finns en tabell över vilka metoder som kan användas och vad de innebär. 

| Metod  | Ändpunkt | Beskrivning | 
| ------------- | ------------- | ------------- |
| GET | /api | Kopplar upp till API |
| GET  | /post | Visar alla inlägg |
| GET  | /post/{id}  | Visar ett inlägg med angett id |
| DELETE  | /post/{id}  | Raderar ett inlägg med angett id |
| PATCH  | /post/{id}  | Uppdaterar ett inlägg med angett id |
| POST  | /post  | Skapar ett nytt inlägg med korrekt angett objekt |


#### Ett objekt som lägger till korrekt information för ett inlägg:
```
{
  "title": "Titel",
  "content": "Inlägg",
  "excerpt": "Utdrag för inlägg",
  "image": "Bild-url",
}
```
